# 语环 X1｜R02 铝塑融合可打印样壳

本版采用你选定的**外露圆头榫接**：大面积铝合金意向主壳，右上角为同色哑光塑料功能区，两个按键融合在这块区域内。所有表面齐平，圆头榫接不会额外凸出。

## 这次拿到的文件

- `stl/`：6 个外壳/按键零件 + 4 个检验试片，均为毫米单位的独立封闭网格。
- `step/`：6 个零件的可编辑实体、2 个榫接试片，以及带 PCB、电池/器件包络和紧固件示意的装配文件。
- `preview/`：正面、背面、爆炸图、内部、接缝细节、俯视图、尺寸与厚度图。
- `reference/`：从真实板框与开槽重建的 PCB 几何，以及原始几何记录。
- `source/`：CadQuery 建模脚本、参数、EasyEDA 实时回读数据和 Blender 渲染脚本。
- `verification/geometry-check.json`：实体、装配干涉、网格和天线位置代理的检查结果。

**现在可以把 6 个零件全部用光固化树脂分开打印，验证装配。** 文件名中的 `metal` 表示以后希望使用铝合金的部分；树脂打印不会变成铝合金。后续可把对应 STEP 交给 CNC 厂做加工评审，尚未作为批量 CNC 定版图纸发布。

BAT1 直立 XH 插座按你授权省略，电池原有引线直接焊接。USB 壳体插脚和电池焊点下方有 0.35 mm 局部下沉位，焊脚/焊点突出 PCB 底面的高度需不大于 0.45 mm；这些位置最薄底板为 0.65 mm。上盖字样为浅凹刻。

闭合使用 **4 颗 M2×5 盘头机牙螺丝和 4 颗 M2 六角螺母**。螺丝长度指头下长度 5 mm，头部外径应 ≤3.8、头高 ≤1.4；设计孔径 2.3、头部避让孔径 4.4。螺母按对边 4.0、高 1.6 建模，六角口袋对边 4.25。

**靠近两个按键的右上角，螺丝和螺母两者都使用尼龙等非金属件**，同样需满足上述外形。其余三个角可用金属件。不要在塑料功能区内添加金属装饰片、磁铁或导电涂层。装配 STEP 的螺丝仅为无螺纹外形与十字槽参考，不是紧固件生产文件。

## 先打印试片，再打印整壳

1. 打印 `x1_fit_coupon.stl`，检查 M2 螺母对边 4.10 / 4.25 / 4.40 三档、按键孔 4.9 / 5.1 / 5.3 三档和 USB 包胶开口。
2. 打印 `x1_joint_metal_coupon.stl` 与 `x1_joint_plastic_coupon.stl`，按实际清洗、后固化工艺完成后试拼，检查 0.20 mm 胶缝。零件应能轻松从垂直方向放入，不靠挤压树脂完成配合。
3. 打印 `x1_battery_slot_gauge.stl`，检查带保护板、封边的实际电池能否通过原 PCB 槽口；再用卡尺量成品最厚处。试片只能检验 XY，厚度另量。
4. 试片合适后，打印 6 个壳体/按键零件。切片导入单位选 mm、缩放 100%；这些 STL 已移到各自原点，上盖已翻面便于布置。分别排版，勿自动对齐当作装配文件。装配位置以 `x1_assembly_reference.step` 为准。
5. 让打印服务商按树脂及设备确定倾角、层厚和支撑。把支撑布置在内侧或后续能打磨的位置，保护圆头榫边缘、1 mm 薄面、按键导孔和四个声孔。此包没有绑定某台机器的支撑和切片参数。

## 装配顺序

1. 将下主壳与下塑料区、上主壳与上塑料区分别试拼。外表面朝平整定位面，用隔离膜防止粘到工装；轻度夹持，确认外面齐平后，从内侧向 0.20 mm 拼缝施加与实际材料相容的胶。胶固化后得到一个下壳组件和一个上壳组件。
2. 圆头榫防止平面内错位；**上下方向的固定依赖胶粘**，并非可反复拔插的锁扣。不要把上壳和下壳沿外圈粘死，四颗螺丝是拆装口。不要让胶流入按键、声孔、USB 或 SD 槽。
3. 从下壳底面的六角口袋放入四颗螺母，必要时用小片胶带暂时固定。螺母上面的肩台承受拧紧载荷。
4. 声孔四周贴同规格薄泡棉环：外径 3.0、内径 1.4、目标压合厚度 0.20 mm；四条声路保持一致并对准 PCB 底部进声孔。泡棉和声学效果需用实板验证。
5. 放入 PCB 和位于 PCB 开槽内的电池。0.20 mm 胶层固定电池；引线沿器件空位布置，不从电池上方叠线。先检查焊脚突出高度。未来换铝件时，需预留并确认焊点与金属之间的电气绝缘，不能把阳极氧化当作唯一绝缘层。
6. 两个按键从上盖内侧装入，法兰防脱，开关提供回弹。合上盖板，四颗螺丝从正面拧入下壳螺母，轻轻锁紧至贴合。按下两键，确认能回弹、不会常压开关；用 USB 插头、SD 卡和实物电池检查适配。
7. 完成一次实板装配后，分别检查录音、四麦进声、按键、USB/SD 和装壳后的蓝牙/Wi-Fi 距离。

## 已验证与待验证

建模脚本已经检查：6 个正式零件均为有效单实体；两两无体积干涉；与真实板框/电池槽、假设最大电池包络及 50 个器件高度包络无壳体干涉；按键设计下压 0.35 mm 不撞壳；紧固件参考外形不撞壳；10 个 STL 的边均恰好由两个三角面共享，网格封闭、体积为正。

射频功能区贯穿上盖、底板及邻近侧壁，没有在塑料下方再留连续铝板。按原 PCB 天线 keepout 矩形作为位置代理计算，距离铝意向实体最小约 **17.97 mm**；靠近天线的角改用非金属螺丝及螺母。该计算不包含 PCB 上已有金属，也不是对实际天线性能的认证。Espressif 官方 ESP32-S3 硬件指南建议外壳中的天线周边保留至少 15 mm，并要求最终产品测试通信距离和吞吐量：
https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/pcb-layout-design.html#general-principles-of-pcb-layout-for-modules-positioning-a-module-on-a-base-board
（2026-10-18 查阅。）

**尚未进行实体打印、实板装配、射频/声学及温升测试。** 电池和器件参考体是包络，不是完整的供应商 STEP。未来加工铝件还要由 CNC 厂核对刀具内角、薄壁夹持、表面处理余量、胶接工艺和绝缘空间；本包适合先验证外观和尺寸。

## 来源与复现

PCB 几何来源：EasyEDA Pro 当前工程 `MeetCard-AI-repair-loop-20261018`，PCB1 文档 `c513f79d0042e6d9` 的实时回读。板框、开槽、器件 XY 和底部进声孔来自原生数据。电池槽不是铺铜禁区，而是实际贯通开槽。此次外壳工作没有改动电子板。

原坐标单位 mil，Y 向上。CAD 转换为：

```
X_mm = (PCB_Y - 98) × 0.0254
Y_mm = (2447 - PCB_X) × 0.0254
```

安装 CadQuery 2.5.2 后，从本目录运行：

```
python3 source/build_hybrid.py --parameters source/parameters.json --out rebuilt
```

可选用 Blender 运行：

```
blender --background --python source/render_hybrid.py -- rebuilt
```

`manifest-sha256.txt` 用于核对交付文件。所有打印尺寸以 STL/STEP 和 `parameters.json` 为准，预览图只用于看结构与外观。
