# 语环 X1 R03｜嘉立创 SLA 打印优化版

**当前建议先打印这一版试装。** 保留铝塑分区、外露圆头榫接和电池嵌 PCB 槽的结构。主面厚度增加以适应树脂后处理；R02 的 7.6 mm 版本仍保留作为薄版设计记录。

本版主体 **110.80 × 84.84 × 9.80 mm**，按键最高 **10.15 mm**。所有壳体先用树脂打印；`metal` 名称表示未来铝件意向，不能把树脂文件的尺寸公差直接作为 CNC 定版。

## 这版实际改了什么

| 项目 | R02 | R03 |
|---|---:|---:|
| 主体厚度 | 7.60 | 9.80 mm |
| 顶板 / 底板 | 1.00 / 1.00 | 2.00 / 2.00 mm |
| 侧壁 | 1.50 | 2.00 mm |
| 榫接胶缝总宽 | 0.20 | 0.40 mm |
| 按键孔 / 键帽直径 | 5.10 / 4.60 | 5.60 / 4.60 mm |
| 按键径向单边间隙 | 0.25 | 0.50 mm |
| 按键法兰厚 | 0.90 | 1.60 mm |
| 定位唇厚 / 侧向间隙 | 0.80 / 0.20 | 1.80 / 0.50 mm |
| 板边定位挡块厚 / 侧向间隙 | 1.00 / 0.25 | 1.80 / 0.50 mm |
| 细导向环与细内筋 | 有 | 取消；由 2 mm 盖板孔导向 |
| 小字与按钮符号 | 浅细雕刻 | 盖板细字改平面贴标；按键符号宽/深 0.80 mm |
| 闭合螺丝 | M2×5 | M2×8，配 M2 螺母 |
| 两个小按键 | 单独文件 | 保留单件，并附可剪料道拼版 |

电池按 **40×60×5 mm** 放入真实板槽，底部胶层 0.20 mm。实际保护板、封边未量；设计检查包络仍为 41.410×61.476×5.20 mm。底板顶面 Z=2.00，电池顶面假设为 7.40，上盖内面 Z=7.80，余 0.40 mm。PCB 底面为 Z=2.25，厚度假设 1.60。PCB 和电池并排，不把 PCB 厚度叠加在电池下面。

## 文件怎么选

`stl/` 内 6 个正式零件：下主壳、下塑料区、上主壳、上塑料区、录音键、回溯键。每个文件一个零件，mm 单位、100% 缩放；同名 STEP 可编辑。上盖 STL 已翻面并分别归零，装配位置请看 `step/x1_assembly_reference.step`。

**两个小按键可以拼在一起打印：** 改选 `stl_optional/x1_buttons_on_sprue_CUT_AFTER_PRINT.stl`，它通过两根 **1.7×1.6 mm** 可剪连接杆连到同一条料道，整个文件是一个连通实体。打印后剪开并精修接触面。不要同时再下单两只独立按钮，否则会重复。

连接杆只接在按钮法兰外缘，不进入底部开关接触杆；剪开后修平法兰外周，保持底部接触杆完整。操作时夹持料道，不掰扯法兰。先打印可选拼版样件再决定是否批量使用。大型外观件保持独立文件，保留各自摆放、支撑和后处理空间。

`stl/x1_fit_coupon.stl` 检查螺母与按键孔：从左到右，第一排六角孔对边 4.30 / 4.50 / 4.70，圆孔直径 5.40 / 5.60 / 5.80 mm；第二排是 USB 包胶窗口。为避免细字失真，试片本身不雕刻小标签，按该顺序识别。

`x1_joint_metal_coupon.stl` 与 `x1_joint_plastic_coupon.stl` 是 2 mm 厚榫接试片，胶缝 0.40 mm。`x1_battery_slot_gauge.stl` 是原 PCB 槽口 1:1 试片，只检查 XY 是否通过，电池厚度仍需卡尺实测。

## 下单和装配

1. 先下单三个配合试片与电池槽口试片；按实际清洗、后固化流程完成后再试拼。按键的拼版方案也先试一套。
2. 正式壳体选普通 SLA 树脂；本设计的小声孔按未喷漆条件评估，若做喷涂，声孔与 LED 孔需要遮蔽并复通。具体层厚、支撑角度由打印方按设备选择。
3. 上主壳与上塑料区、下主壳与下塑料区分别试拼。在平整工装上保证外表面齐平，从内侧用相容胶粘合。圆头榫限制平面内错位，Z 向依靠胶；不要把上下两半外圈粘死。
4. 四颗 M2 螺母从底面装入六角口袋，必要时胶带临时固定。**四颗螺丝改为 M2×8**（头下长 8 mm），头径≤3.8、头高≤1.4；螺母对边 4.0、高 1.6。两个按键附近的右上角，螺丝和螺母两者都用非金属件；其它三角可用金属。
5. 不装 BAT1 直立 XH 插座，按既有授权直接焊电池引线。USB 脚与电池焊点下仍有 0.35 mm 下沉位，最低局部底厚 1.65 mm；焊脚突出板底不超过 0.50 mm。金属替换件还要确认绝缘空间。
6. 四声孔位置不动，直径 1.40 mm、底板声路 2 mm；使用内径 1.4、外径 3.0、目标压合厚度 0.25 mm 的同规格泡棉环，避免漏声串腔。新旧壳体的声路长度不同，需要重新做四麦实测。
7. 两只按钮从盖板内侧装入，合壳轻锁四颗螺丝。检查按键回弹、USB 插头包胶、SD 卡插拔，再上实板验证录音与装壳后的无线连接。

## 对照你给的嘉立创指南

参考原文： https://www.jlc-3dp.cn/technicalColumnsDetails/27832.html （2026-10-19 查阅，含图片表格。）

本版对照主要壁厚、活动间隙、定位结构、孔深、细字以及第十节拼接打印要求调整。指南推荐一个文件一个零件；可选按键拼版遵守连接杆超过 1.5 mm、每文件连接件少于 10 个的约束，但这种打印方案仍可能由厂家评估外观和变形。它是一个可选下单文件，不等于工厂已接受订单。

**局部仍需厂家审图：** M2 螺母口袋周围不能保证处处都有 2 mm 残壁；外围实体墙分担受力，需轻锁并做实物验证。局部焊脚避让底厚 1.65 mm。PCB 支承是低而宽的台阶，不是细长定位柱。所有小声孔与 LED 孔按未喷漆处理，不拿本版承诺喷涂后不堵孔。为满足细字可读性而给的大字号平面贴标 SVG 不直接参与树脂打印。

这是一份**对照指南优化的装配样壳**，不声称每处细节均已获厂家认证，也不把拆分视为能绕过材料强度限制。

## 验证与复现

`verification/geometry-check.json` 记录：6 个壳体/按钮单实体、互不穿插；与真实 PCB 外形和槽、电池假设包络以及 50 个器件高度包络无壳体体积干涉；按钮下压 0.35 mm 不撞壳；紧固件外形避让通过；导出的全部 STL 封闭且体积为正。拼版文件也为单一实体。天线位置代理至新增铝意向件仍约 17.96 mm；这只是几何校验，不包括 PCB 已有金属，也不能替代 RF 测试。

尚未实际打印、装配、上电或测试声学/无线性能。器件高度、电池成品外形与板厚需与实物核对。本文所述铝件只是未来材料意向；此版本先用于树脂装配验证。

安装 CadQuery 2.5.2 后运行：

```
python3 source/build_print_r03.py --parameters source/parameters.json --out rebuilt
blender --background --python source/render_print_r03.py -- rebuilt
```

后者用于生成外观参考图。所有交付 STL/STEP 尺寸以参数文件为准。此前 PCB、固件和 Android 工程未因这次外壳调整改变。
