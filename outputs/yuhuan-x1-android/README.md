# 语环 X1 Android Demo 0.1.0

对应用户提供的 `stitch_x1.zip` 四页设计，以 Kotlin / Jetpack Compose 实现。界面保留浅色、深绿色、音频时间轴和四个底部入口；设备协议对应独立四麦、双按键固件 `0.1.0 / independent-mic-20261018`。

## 首版功能

- BLE 搜索、Android 系统配对、加密特征通信，设备连接使用前台服务与持续通知。
- 连接后校时，获取录音清单、保存标记与实际状态；默认自动同步，可关闭。
- 手动录音开始 / 暂停 / 继续 / 结束；回溯保存过去 1–24 小时。设备离线时相应操作禁用。
- BLE 分片、请求号、CRC32 与连续偏移检查；Wi-Fi 局域网传输、断点续传，失败可改用 BLE。
- 手机私有目录保存 ADPCM WAV；验证文件后原子更名，最后发送准确字节数 ACK。ACK 不删除设备录音。
- 录音库搜索、保存 / 手动 / 待同步筛选，日期分组，重命名与备注。
- 保存标记按实际样本区间裁切；同一手动录音的暂停前后属于同一组，排除暂停时间。重叠标记不重复音频。
- 本地 ADPCM 解码、流式播放、倍速、跳转、由本地音频计算的波形；按区间导出 PCM WAV，通过 Android 分享面板导出。
- 分别管理手机副本与设备保存标记；删除操作说明共享片段可能影响其他录音。
- 无账号、服务器、云上传、手机麦克风权限或远程字体依赖。

“助手”“文字”“摘要”显示尚未分析，**尚未接入 ASR、LLM、AI 摘要、系统日历或提醒排程**。不显示虚构分析结果。

## 与 Stitch 设计的必要修正

原始导出中的一部分示例值不是硬件规格。本工程使用真实固件数据：

| 设计示例 | 本工程 |
|---|---|
| 44.1 / 48kHz 无损 PCM | 设备保存 16kHz 单声道 IMA ADPCM；分享时解码为 PCM WAV，不能恢复已损失信息 |
| 固定电量 78%、充电状态 | 固件只有电池电压，显示 V；不伪造 SOC 或充电状态 |
| 固定 32GB Flash、已用容量 | 显示固件返回的 SD 剩余空间；总容量不可得时不填假值 |
| BLE 5.3、5GHz Wi-Fi | 不标注未核实的 BLE 版本；引导 2.4GHz Wi-Fi |
| 30 分钟回溯、长按回溯 | 固件支持整小时 1–24；实体第二键连按 N 次保存 N 小时 |
| 350ms 按键校准、长按 5s 配对 | 不提供固件没有的设置或按法；连按窗口 500ms |
| 设备“永久保存”、保证零丢失 | 显示保存标记防循环覆盖；不承诺 SD 不损坏或电池不停机 |
| 测得的实时声响时间轴 | 只显示已获取的录音区间，播放器波形来自本地解码 |

原始 HTML 和截图是参考资料，没有作为 WebView 页面载入，也没有执行其远程脚本。

## 设备连接与使用

1. 设备使用对应固件，插入已格式化的 SD 卡并开机。
2. App「设备 → 连接语环 X1 → 搜索」，允许附近设备权限；Android 11 及以前搜索 BLE 需要定位权限，App 不收集地理位置。
3. 点选设备，确认 Android 的系统配对提示。设备清单在加密连接后获取。
4. 自动同步默认开启。大量历史录音优先在「同步中心」配置设备 Wi-Fi；手机与设备应连接同一局域网，设备使用 2.4GHz 网络。
5. 回到同步中心继续同步。Wi-Fi 凭据通过 BLE 下发；App 不保存 Wi-Fi 密码。设备的 Bearer token 使用 Android Keystore AES-GCM 加密保存。
6. 已同步录音可在离线状态下播放、重命名、备注和分享。重要录音先分享导出，再考虑卸载 App。

设备仅暴露本地 HTTP；本工程只接受数字形式的私有 IPv4 地址，并通过 Wi-Fi 网络请求，禁止重定向。传输仍是固件现有的 HTTP + Bearer token，没有 TLS。

## 编译

需要 JDK 17、Android SDK Platform 36、Build Tools 36.0.0。最低 Android 8.0 / API 26，目标 API 36。

```sh
./gradlew assembleDebug
./gradlew testDebugUnitTest
./gradlew lintDebug
```

使用 Android Studio 打开本目录，配置 SDK；命令行可设置 `ANDROID_HOME`，或在仅本机使用的 `local.properties` 写入 `sdk.dir=...`。不要把 `local.properties` 作为可移植工程的一部分。

版本固定：Gradle 8.13、AGP 8.13.0、Kotlin 2.1.20、Compose BOM 2025.06.01。这些是本工程选择的固定版本，不代表最新版本。发布签名尚未配置；交付 APK 使用开发签名，仅用于 Demo 测试。

## 验证与实物联调

主机测试检查 BLE 帧 CRC / 偏移 / 过期请求、无符号 64 位 ID、重叠保存区间与暂停裁切、断点接收与落盘后 ACK。音频 fixture 来自既有固件编码器，解码结果与独立 FFmpeg 输出比较。

安卓测试检查离线录音库、播放与详情页、AI 未接入状态、设备页和连接流程；测试使用单独测试 APK 注入的短音频，不给普通用户预装假录音。最终执行结果见 `release/verification.md`。

实板尚需验证：BLE 配对与各 Android 厂商兼容性、四麦板录音内容、Wi-Fi 联网与吞吐、长时间下载、锁屏 / 后台 / 断链恢复、低空间与真实断电。模拟器不替代这些测试。

## 当前边界

- 自动同步在用户启动的设备连接服务运行期间执行，约每 30 秒检查；断开后尝试重连已记住的设备。系统强制停止、权限撤销、厂商省电策略可能中断服务。没有开机自启或绕过系统限制。
- 活动录音约一分钟封口一次，因此最新一分钟可能暂不在清单里。24 小时是录音样本时间，断电期间不计入；未校时片段显示“未校时录音”。
- 默认按小时汇总循环片段；保存录音按标记和手动分组展示，不会把一分钟文件全部铺满首页。单次清单最多读取 32,000 个片段，超出会报错并保留现有手机文件。
- 不访问手机麦克风，不提供实时监听。播放仅在 App 前台，切到后台会暂停；连接和同步服务可继续。
- 播放流式解码，导出会生成临时 PCM WAV，约每小时 115MB；空间不足时拒绝导出。过期分享缓存会在下次导出时清理。
- App 私有目录不参与系统自动备份。卸载会删除手机副本、备注和目录，设备副本是否仍可用取决于它的循环窗口 / 保存标记。
- 现有固件没有真正的持久设备 UUID、SD 介质 UUID、文件内容 hash 或目录代际编号。App 以 BLE 地址分开存储，发现同 ID 的元数据冲突时另开档案；完全相同的计数重置仍不能可靠识别。重新格式化 SD 或更换设备后，正式产品应增加这些协议字段。
- 固件没有“只保护某个任意旧片段”的命令，因此录音详情没有伪造“星标后保护设备”的按钮；可使用回溯保存，已有标记可解除。
- 需要绑定账号、远程存储或模型调用时，应单独增加实际后端与数据流程；首版不包含这些功能。

## 目录

`core/` 纯 Kotlin 协议与音频；`transport/` BLE / LAN；`data/` 本地目录与密钥；`sync/` 接收、连接服务和设备控制；`audio/` 播放；`ui/` 原生界面。

`docs/DEVICE_PROTOCOL.md` 是对应的设备协议；`design-reference/` 保留用户提供的原始 Stitch 导出，作为视觉参考，不参与 App 运行。
