# 语环 X1 安卓 Demo 0.1.0

安装同目录的 `语环X1-Android-Demo-0.1.0.apk`，需要 Android 8.0 或以上。它使用开发签名；手机如提示安装来源，请仅为此次已下载的 APK 允许相应安装来源。

## 第一次使用

1. 安装并打开 App。未连接录音卡时录音库为空，不会出现预装的假录音。
2. 实板刷入此前交付的独立四麦、双按键固件 `0.1.0 / independent-mic-20261018`，插入 SD 卡开机。
3. 在「设备」页连接语环 X1，允许附近设备权限并完成系统蓝牙配对。Android 11 及以前 BLE 扫描还需定位权限。
4. 连接后自动校时、获取清单并开始同步。大量录音可在同步中心配置 2.4GHz Wi-Fi，让手机和设备连接同一局域网。
5. 「今天」控制手动录音或保存过去 1–24 小时；「录音」播放、备注、重命名和分享手机里的音频。离线也可播放已同步内容。

手机是 Demo 的本地存储端，不需要服务器。AI 转写、摘要、提醒与日历尚未接入；「助手」页会显示待接入状态。实物蓝牙和 Wi-Fi 仍需联调，当前通过的是编译、核心测试和模拟器界面流程。

卸载 App 会清除手机私有目录中的录音与备注；重要录音先通过分享导出。手机副本删除与设备回溯保存标记解除是不同操作。

`语环X1-安卓工程-0.1.0.zip` 包含源码、Gradle wrapper、设备协议、原始视觉参考、界面截图、开发版 APK 和验证报告。解压后用 Android Studio 打开 `yuhuan-x1-android`，配置 JDK 17、Android SDK 36 和 Build Tools 36.0.0。详细编译方法和功能边界见工程根目录 README。

`语环X1-安卓界面预览.png` 使用 Android 模拟器与单独测试 APK 注入的短音频生成，不表示设备已连接或已获得实物录音。
