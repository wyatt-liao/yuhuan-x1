# 语环 X1 GitHub 项目

仓库：https://github.com/wyatt-liao/yuhuan-x1

可见性：私有。主分支：`main`。整理日期：2026-10-19（Asia/Shanghai）。

包括当前目录的语环 X1 项目交付：EasyEDA 原生 PCB、审查与改线证据、固件源码和编译产物、Android 工程与 APK、R01/R02/R03 外壳 CAD/打印件/预览，以及产品影片与源文件。

外壳先看 `outputs/yuhuan-x1-enclosure-r03/README-打印与拼版说明.md`。该版主体厚 9.80 mm，按键有独立和可剪料道拼版两种文件；外露圆头榫接保留。薄版 R02 的 7.60 mm 方案保留在历史目录。

工作区的 SDK、工具链、模拟器、下载缓存、编译缓存、本机连接状态与本机路径配置不上传。解压产生且内容完全相同的 `yuhuan-x1-enclosure-r02 2` 重复目录只保留标准 R02 一份。各历史 ZIP 保留原来的交付快照，优先阅读当前工程 README。

实板与树脂样壳仍需实测；几何检查和编译通过不等于已经完成量产验证。
