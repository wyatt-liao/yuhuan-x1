## 修改内容

第二按键 SW2.1 从 EN 改到 BTN2 / GPIO15 / U1.8；SW2.2 保持 GND，原有 EN 上拉、复位电容和 U1.3 的连接保留。SW1 保持 GPIO0。

四只麦克风保持共用 3V3 供电，每只拥有独立 CLOCK 和 DATA；没有增加负载开关、MOS 管或其他元件。

| 麦克风 | CLOCK | DATA | SELECT |
|---|---|---|---|
| MIC1 | GPIO4 / U1.4 / I2S_SCK | GPIO6 / U1.6 / I2S_DIN12 | GND |
| MIC2 | GPIO16 / U1.9 / CK2 | GPIO5 / U1.5 / D2 | 3V3 |
| MIC3 | GPIO17 / U1.10 / CK3 | GPIO7 / U1.7 / I2S_DIN34 | GND |
| MIC4 | GPIO18 / U1.11 / CK4 | GPIO8 / U1.12 / D4 | 3V3 |

旧网名 I2S_DIN12、I2S_DIN34 保留用于 MIC1、MIC3，名字不再代表两个麦克风共享。数据分别引出，避免停钟/启动时共享 DATA 的占用问题。GPIO5 原来的 I2S_WS 标签已移除；PDM 接口不用独立 WS。

## 同步、校准与省电

采用同一个 I2S0 PDM RX 硬件时钟经 GPIO Matrix 分发，四只麦克风不是四套自由运行时钟。数据四路同时进入同一接收器。平时只让 MIC1 CLOCK 工作，其他 CLOCK 拉低；人声触发后连接同一时钟，MIC1 继续录制，固件约300ms后才使用新麦克风数据。

IM69D130 原厂资料的 Clock Off Mode 要求 CLOCK 拉低；表5给出启动/模式切换稳定时间：±0.5dB约20ms、±0.2dB约50ms。300ms是本 Demo 加上滤波/DMA余量的设计取值，仍需样机验证。原厂资料副本及读取文本存于证据包，来自库器件关联的 LCSC 数据手册页。

这种接法允许同步采集，分开走线本身不构成必须使用四套校准时钟的理由。但仍须实测：声道顺序、四路增益、固定相对延迟、反复停钟唤醒后的延迟是否一致，以及外壳声孔对声学响应的影响。PCB DRC 不验证这些事项。

当前固件做四麦声道选择，保存16kHz单声道 ADPCM WAV；没有声称已完成立体声输出、阵列校准、波束成形或 AI 降噪。手机 App 和 AI 提醒尚未实现，已交付本地 BLE/Wi-Fi 协议与手机后端模拟器。

2000mAh 电池续航仍需电池侧电流实测。停掉三只麦克风只降低相应麦克风/时钟负载，主控、SD、无线仍耗电，不能按四倍续航计算。
