主控为 ESP32-S3-WROOM-1-N16R8。当前方案将四只麦克风的时钟、数据分开引出，双按键分别用于手动录音和暂停 / 回溯保存；具体 GPIO 以固件表格和原生工程为准。

电池方案为带保护板的 504060、3.7 V、2000 mAh，置于 PCB 槽内。外壳建模按电池引线直焊、移除直立 BAT1 XH 插座考虑，电池成品外形尚未实测；投板与装配前应核对原生工程和实际 BOM。

这里保留的是设计、修改和检查记录，尚无实板上电、录音或长时间验证结果。历史审查结论对应其记录时的板子状态，后续改线见对应说明。
